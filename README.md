# Little Lemon – Front-End Capstone Project

This project is the final capstone for the Meta Front-End Developer Professional Certificate.  
It demonstrates a fully responsive front-end application for a fictional restaurant called Little Lemon.

## Tech Stack

- React (Functional Components and Hooks)
- JavaScript (ES6)
- CSS (Responsive Design, Flexbox)
- React Router
- Form Handling and Validation

## Features

- Pages: Home, About, Menu, Booking
- Client-side routing using React Router
- Reservation form with input validation
- Clean and responsive UI across devices
- Semantic HTML and accessibility practices
